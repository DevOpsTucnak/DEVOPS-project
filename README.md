# DevOps Training Project

Це простий вебсайт-проєкт для практичного вивчення DevOps.

## Поточний етап

Ми починаємо з Git. Проєкт навмисно простий: основна мета — використовувати його як навчальний об'єкт для DevOps.

## Структура

- `index.html` — сторінка сайту
- `styles.css` — стилі
- `script.js` — JavaScript

## Як запустити

Docker поки не потрібен.

Просто відкрий `index.html` у браузері або запусти файл через Visual Studio Code / Visual Studio.

## Подальший розвиток

Проєкт буде поступово використовуватися для практики:

1. Git
2. Linux
3. Docker
4. CI/CD
5. Ansible
6. Kubernetes

Нові технології додаємо тільки тоді, коли вони потрібні за roadmap.
